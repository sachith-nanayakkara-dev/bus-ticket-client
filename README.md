# Bus Ticket Client

This is a simple Java client application for simulating bus ticket operations.

## Project Structure
- **src/main/java/org/sachith/ClientSimulator.java**: Main client simulator source code.
- **build.gradle**: Gradle build configuration.
- **build/**: Build outputs and generated files.

## Build & Run

### Prerequisites
- Java 8 or higher
- Gradle (or use the provided `gradlew`/`gradlew.bat` scripts)

### Build
```
./gradlew build
```

### Run
```
./gradlew run
```

Or run `java -jar bus-ticket-client.jar`
